# Prior knowledge: standard OSS workflow

The user is already comfortable with the post-review OSS hand-off — re-request review, waiting for maintainers, polite pings, not scope-creeping the PR. Lesson 10 on "close the PR loop" was replaced with MCP integration to stay in their zone of proximal development.

**Implications:** Do not re-teach merge etiquette or contributor waiting games. OSS references (`pr-merge-etiquette.html`, `oss-workflow.html`) remain available but are not curriculum drivers. Future lessons should focus on Cursor power-user skills: MCP, hooks, skills, cloud agents, debugging workflows.
