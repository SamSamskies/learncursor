Lesson 1 · ~8 minutes

Choose the Right Surface

The most common mistake solo builders make is opening Agent for everything. Power users match the tool to the job.

Cursor is not one AI feature — it is four surfaces, each optimized for a different kind of work. Your mission is to ship app ideas fast. That starts with knowing which surface to reach for before you type a single prompt.

The four surfaces

type Tab — autocomplete

Finishes the line you're writing. Best for boilerplate and obvious completions. Never leave the keyboard.

Cmd+K Inline Edit

Select code, describe a change, get a diff in place. Best for local edits — rename a function, tweak one component.

Cmd+I Agent

Full co-builder. Reads files, writes code, runs terminal commands. Best for features, bugs, and multi-file work.

Shift+Tab Plan Mode

Agent researches and writes a plan before touching code. Best for new app ideas and anything architecturally unclear.

Rule of thumb for solo builders
New idea or big feature → Plan first.
Known task spanning files → Agent.
Small edit in one place → Inline Edit.
Finishing what you're typing → Tab.

Keep the surfaces reference open while you work. You'll internalize this quickly — until then, glance at it before every session.

Check your understanding

1. You want to rename a variable inside one function. Best choice?

2. You have a new app idea — a habit tracker — and no code yet. Best first step?

3. Agent built the wrong architecture. What do power users do?

Do this now

5-minute win: open Cursor on any folder (even an empty one) and run this exact Agent prompt in Plan Mode:

  1. Press Cmd+I to open Agent
  2. Press Shift+Tab until you see Plan
  3. Paste this prompt:

I want to build a simple personal habit tracker as a web app.
Ask me 3 clarifying questions, then propose the thinnest plan to get a working prototype in one session.

Review the plan Agent produces. You don't need to build yet — the win is seeing Plan Mode in action.
