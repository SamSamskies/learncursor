Lesson 18 · ~12 minutes

Cursor for iOS

Your phone is not a tiny IDE. It is the control plane for agents that already know how to build.

Cursor for iOS launched June 29, 2026 in public beta. If you completed Lesson 14, you already know cloud agents: isolated VMs, Max Mode, PRs, the Agents Window. The iOS app is the same backend — cursor.com/agents in your pocket. Agents you start on your phone show up on desktop; agents you start at your desk show up in the mobile inbox.

For your mission — solo app building without being chained to a desk — this is the surface for kick off, walk away, review, merge. Keep the Cursor iOS reference handy.

What it is (and is not)

On your phoneStill on the web / desktop
Start cloud agents on any repo + branch Full editor, terminal, file browser
Watch live transcripts, send follow-ups Configure secrets and cloud environments
Review diffs, merge PRs, Fix with Agent Add or manage MCP servers (pick per run on mobile)
Voice input, slash commands, skills, Design Mode Automations, rules, and skills configuration
Push notifications + Live Activities (up to 8 agents) Billing, usage, team admin

Official docs: Cursor for iOS. Requires a paid plan with cloud agents (Pro and above). iPhone, iOS 26+, English. Android is planned.

Three ways to use it

Cloud agent Pick a repo, choose Cloud as the worker, describe the task. The agent runs in Cursor's cloud VM — same as the web. Lock your phone; it keeps working.
Remote Control Start Agent on your Mac, run /remote-control, then continue from your phone. The agent loop moves to the cloud but terminal, edits, and tests run on your Mac. Your repo and secrets stay local.
Review only Open an existing agent or PR from the inbox. Read the diff, comment, squash-merge, or tap Fix with Agent on a failing check — no new task required.
Remote Control needs setup on desktop first.
Cursor 3.9.8+, enable under Agents Window → Settings → Agents. Your Mac must stay awake and online. Git-backed workspace required. See Remote Control docs.

Agents started on mobile are tagged source: iosApp so you can tell where a run originated. Through July 5, 2026, Composer 2.5 runs are 75% off in the mobile app (launch blog).

First launch checklist

  1. Install from the App Store
  2. Sign in with your Cursor account (SSO if your org requires it)
  3. Confirm GitHub/GitLab is connected — dashboard if not
  4. Pick a repo you know well (your habit tracker or LocalLab)
  5. Start a small cloud task: "Run tests and report pass/fail. Do not open a PR."
  6. Lock the phone; wait for the push notification

Check your understanding

1. What is Cursor iOS primarily?

2. Where does a cloud agent started on iPhone run?

3. What stays on the web, not in the app?

Do this now

One mobile agent, end to end

  1. Install — get Cursor from the App Store and sign in.
  2. Pick a repo — choose a project with cloud environment already set up (from Lesson 14).
  3. Start small — cloud worker, prompt: Run the test suite. Report pass/fail counts only. Do not open a PR.
  4. Walk away — lock the phone. Confirm you get a notification when the turn finishes.
  5. Cross-check — open the same run at cursor.com/agents or the desktop Agents Window. Same transcript, same result.

Optional stretch: at your desk, start an Agent on a real task, run /remote-control, then send one follow-up from your phone.

You are done when you have seen one agent start on mobile, finish while your phone was locked, and appear on desktop.
