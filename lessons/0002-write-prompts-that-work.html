Write Prompts That Work

Picking the right surface gets you in the door. A clear prompt is what gets correct code on the first or second try.

You already know when to open Agent or Plan Mode (Lesson 1). This lesson covers what to type once you're there. Power-user prompts share the same four-part shape — whether you're building a habit tracker or fixing a bug in someone else's repo.

The four-part prompt

Goal One concrete outcome. Not "improve auth" — "redirect to /dashboard after login succeeds."
Scope What's in this message, and what's explicitly out. One distinct task per Agent chat.
Constraints Stack, style, files to touch or avoid. "No new dependencies" saves you a refactor later.
Done-when How you'll verify success. "Run npm test" or "open localhost and add a habit."

Keep the prompt anatomy reference handy. You'll internalize the template fast — until then, mentally check all four boxes before you hit Send.

Bad prompt vs good prompt

Vague — Agent guesses
Make the habit tracker better. Add whatever features you think are missing.
Four-part — Agent executes
Goal: Add a habit list page that reads/writes localStorage.
Scope: List view only — no edit or delete flow yet.
Constraints: Vanilla HTML/CSS/JS in a single index.html.
Done-when: Run `python3 -m http.server` — I can add a habit and see it persist after refresh.
@ mentions — when and when not
Type @ to attach files, folders, terminal output, or git diffs. Use @filename when you know what's relevant. When you don't — describe the symptom and let Agent search. Official docs say over-attaching wastes context; under-specifying the goal wastes your time.

Check your understanding

1. Which prompt gives Agent the best shot at one-shot success?

2. Login fails but you don't know which file. Best approach?

3. Agent finished a feature. What separates power users here?

Do this now

5-minute win: take the habit-tracker plan from Lesson 1 (or any small idea) and send Agent this exact shape — filled in with your details:

  1. Open Agent (Cmd+I) — Agent mode, not Plan
  2. Paste your four-part prompt from the builder above
  3. Let Agent implement, then run your done-when step yourself
  4. If it fails, start a new chat with a refined prompt — don't patch endlessly in one thread

The win isn't a perfect app — it's a prompt that produces runnable code you verified.
