# Mission: Cursor Power User for Solo App Building

## Why

You want to turn app ideas into working software quickly — without a team, without reinventing your workflow every time. Cursor should feel like a reliable co-builder: you describe what you want, it ships a runnable slice, and you iterate from there. You also want to contribute confidently to open source projects you didn't start.

## Success looks like

- Start a new app idea and reach a working first version in a single focused session
- Know which Cursor surface to reach for (Tab, Inline Edit, Agent, Plan) without thinking
- Write prompts that get correct results on the first or second try
- Set up project rules once so every new repo inherits your preferences
- Clone an unfamiliar OSS repo and make a meaningful contribution using Agent

## Constraints

- Solo builder — no team rules dashboard, no enterprise setup
- Builds for personal use; occasional open source contributions
- Learning happens in this workspace over multiple sessions, not one marathon

## Out of scope

- Enterprise team administration and Team Rules
- Replacing fundamental programming knowledge (you still need to read diffs)
- Specific framework tutorials (React, Rust, etc.) — those come up in context per project
