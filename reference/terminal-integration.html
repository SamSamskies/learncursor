Terminal Integration

Three surfaces — integrated terminal, external shell, Cursor CLI.

Pick a surface

SurfaceBest for
Integrated terminal Agent runs commands; you watch output; verify loop; @Terminals
External terminal Hook script tests before wiring; manual verify; bypass live hooks
Cursor CLI (agent) Agent from any directory; headless scripts; resume sessions; CI

@Terminals

Type @Terminals in Agent chat to attach integrated-terminal output. Use when a command already failed and Agent needs the exact error text. 

npm test failed with this output.
Fix the failing test only.
@Terminals
Done-when: npm test — all green.

Cursor CLI essentials

# Install (macOS)
curl https://cursor.com/install -fsS | bash

# Interactive — same modes as editor
agent
agent --mode=plan "add rate limiting to /api"

# Headless — scripts and CI
agent -p "summarize recent git changes" --output-format text
agent -p --force "fix lint errors in src/"

# Resume
agent ls
agent resume

CLI vs editor

SharedEditor-only
Rules, skills, MCP config Diff review UI, inline edit
Agent / Plan / Ask modes @ file picker, browser tools
Run Modes + sandbox (local) Remote Control, cloud handoff UI

Troubleshooting

  • Truncated output → disable Powerlevel10k when CURSOR_AGENT is set
  • Agent hangs after command → Legacy Terminal (Settings → Agents)
  • Hook blocks your test command → test script in Terminal.app first
