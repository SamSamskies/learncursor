Session flow

1 — Spark
  1. One sentence: who uses it, what problem, one core action.
  2. Cut scope until buildable in ~2 hours.
2 — Plan
  1. Plan Mode · lock frontier model (not Auto).
  2. Answer agent questions · approve plan before Build.
  3. Plan must name: stack, folder layout, first slice, verify command.
3 — Bootstrap
  1. New repo · .cursor/rules/ with stack + verify expectations.
  2. Scaffold from plan · initial commit.
4 — Build + verify
  1. One feature slice at a time · @ files for context.
  2. After each slice: run tests · read diff · fix before next slice.
5 — Ship slice
  1. Minimal UI in browser · one happy path end-to-end.
  2. Smoke test manually or with Playwright MCP.
6 — Review + push
  1. /review-bugbot on branch changes · fix findings.
  2. Optional: .cursor/BUGBOT.md · push · open PR.

Done when

CheckPass?
App runs locally without hand-fixing files
One core user action works in the browser or CLI
Tests or verify command green
Project rules committed
Local Bugbot review run (or no diff to review)
