PR Review Loop

Read → fix little → verify → reply. Repeat until merged.

Four steps

  1. Paste — review comments or PR URL into Agent; ask what's valid
  2. Scope — one comment per prompt; combine only if tightly coupled
  3. Verify — same local command as before (their README test)
  4. Reply — push commit; comment "Fixed in [sha]" on each thread

Fix prompt template (one comment)

PR review on @path/to/file — one change only: [paste single comment] No other changes.

Repeat per comment. Two commits map cleanly to two review threads.

Triage table

Comment typeAction

Subjective style Match repo patterns if cheap; else ask
