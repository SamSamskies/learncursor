Cursor iOS

Mobile control plane — same agents as web and desktop · public beta (June 2026)

Requirements

  • iPhone, iOS 26.0+, English
  • Paid plan with cloud agents: Pro, Pro+, Ultra, Teams, Enterprise
  • GitHub/GitLab connected via dashboard
  • App Store

Three mobile modes

ModeWorkerWhen
Cloud agent Cloud VM (or Self-Hosted Pool) Away from desk; long tasks; same as cursor.com/agents

My Machines Registered Mac Start from phone; execution on your machine
Review — Read diffs, merge PRs, Fix with Agent on failing checks

Device handoff

Mobile ↔ desktop ↔ web share one inbox. Agents started anywhere appear everywhere. Mobile runs tagged source: iosApp.

Remote Control checklist

  1. Cursor desktop 3.9.8+
  2. Open Agents Window (Cmd+Shift+P → Open Agents Window) — not the Editor sidebar
  3. Enable: Agents Window → Settings → Agents → Remote Control (toggle is not in Editor settings)
  4. Git remote on workspace; Mac awake + online
  5. Run /remote-control in Agent input, then send next message
  6. Open session in iOS inbox
