Verify Loop

After Agent finishes — before you accept the diff.

Three-step check

  1. Scope — did Agent touch only what you asked for?
  2. Patterns — does the diff match your project rule?
  3. Done-when — run your verification command yourself

Outcome → action

ResultDo this
All green Accept. Move to next plan step with a thin prompt.
One small bug in one file Inline Edit (Cmd+K) on the broken lines.
Wrong approach or multi-file miss Revert, new Agent chat, refined Goal + Scope + Done-when.
Agent ignored a rule New chat: paste the rule bullet it missed + the failing output.

While Agent runs

Watch the diff stream → wrong file or direction? Stop (Cmd+Shift+Backspace) → redirect or revert early. Don't wait for a full bad build.

Self-review prompt (optional)

@Branch Review my changes. Check for bugs, missing error handling, and anything that breaks our test patterns.
