UI Verify

Backend tests green is not enough for a personal app.

Four-step check (UI slices)

  1. Scope — pages and API wiring only? No surprise refactors?
  2. Patterns — matches project rule (stack, folder layout)?
  3. Tests — run npm test yourself
  4. Run — start dev server, click the happy path in a browser

Smoke test script (habit tracker)

npm run dev → open localhost → add a habit → appears in list → toggle today → visual state changes → reload page → toggle state persists → delete habit → gone from list

Outcome → action

ResultDo this
Tests green, browser broken Inline Edit on the fetch/DOM lines — not a new Plan.
Browser OK, tests red Fix tests first — UI may be masking API regressions.
Wrong page structure or missing route Revert, tighten Plan scope, rebuild.
All four green Working first version — iterate with thin prompts.

Done-when line (copy into prompts)

Done-when: npm test green; npm run dev; browser smoke test passes (add, toggle, reload, delete).
