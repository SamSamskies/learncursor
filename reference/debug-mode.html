Debug loop

  1. Hypothesize — explore files, list possible causes
  2. Instrument — add logs to local debug server (Cursor extension)
  3. Reproduce — you run the steps; agent captures runtime data
  4. Analyze — read logs, confirm root cause
  5. Fix — small, targeted change
  6. Verify + clean up — re-run; agent removes instrumentation

Agent vs Debug

AgentDebug
Reads code, guesses fixRequires reproduction + logs first
Fast for obvious bugsBetter for timing, regressions, heisenbugs
@Terminals for failuresStructured instrumentation loop

Good fits

  • Bug reproduces but cause not obvious from reading code
  • Race conditions, async ordering
  • Performance / memory leaks
  • Regressions — "it used to work"
