Create an automation

  1. Web editor — cursor.com/automations (reliable; fill trigger, repo, prompt yourself)
  2. Agents Window + /automate — Agent drafts settings; you review and save (if handoff works)
  3. Marketplace — start from a template, customize

Setup order (editor)

Trigger → Tools → Prompt → Repo scope → Save & activate

Prompt tips

  • Reference committed project skills by name if the repo has them
  • State pass/fail criteria — when to comment, open PR, or do nothing
  • Match enabled tools (don't ask for Slack if tool is off)
  • Set output format: summary comment, issue body, memory note

Billing & identity

  • Automations run as cloud agents — billed to your usage pool (private scope)
  • Always Max Mode — no toggle off
  • Private automations open PRs as your GitHub account; comments appear as cursor
  • Requires dashboard GitHub for PR triggers — not the same as local GitHub MCP
