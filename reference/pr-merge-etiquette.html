PR Merge Etiquette

Your job ends at "ready for review." Theirs starts at merge.

Done-when (contributor side)

  1. CI green (or you explained a flaky failure)
  2. Every review thread replied to or resolved
  3. Test plan in PR description still accurate
  4. Re-request review clicked (if the repo uses it)

While waiting

DoDon't
Work on a new branch or project Push unrelated commits to the same PR
Watch for new review comments Force-push unless asked to rebase
One polite ping after ~1–2 weeks silence @-mention maintainers daily

Polite ping template

Friendly bump — CI is green and both review threads are addressed. Happy to adjust anything else. Thanks for maintaining this project!

After merge

  1. GitHub closes linked issue (#391) automatically if PR body says Fixes #391
  2. Delete your remote feature branch when done (optional cleanup)
  3. Pull upstream master before your next contribution to the same repo
