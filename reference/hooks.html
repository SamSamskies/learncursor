hooks.json template

{ "version": 1, "hooks": { "beforeShellExecution": [ { "command": ".cursor/hooks/block-force-push.sh", "matcher": "git push", "failClosed": false, "timeout": 10 } ] } }

Gate script template

#!/bin/bash input=$(cat) command=$(echo "$input" | python3 -c "import sys,json; print(json.load(sys.stdin).get('command',''))") # ... your logic ... echo '{"permission": "allow"}' exit 0 # permission values: allow | deny | ask # exit 0 = success; exit 2 = block

Observe script template

#!/bin/bash input=$(cat) command=$(echo "$input" | python3 -c "import sys,json; print(json.load(sys.stdin).get('command',''))") echo "$(date -u +%Y-%m-%dT%H:%M:%SZ) $command" >> .cursor/hooks/shell-audit.log exit 0

Setup loop

  1. Pick narrowest event for your goal
  2. Write script in .cursor/hooks/ — read stdin, print JSON if gating
  3. Test in Terminal.app — pipe sample JSON before wiring
  4. Create .cursor/hooks.json with version: 1
  5. chmod +x the script; save — Cursor reloads on save
  6. Trigger via Agent; debug via Settings → Hooks or Hooks output channel
