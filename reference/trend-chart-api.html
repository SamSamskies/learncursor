Trend Chart API

LocalLab — marker time series across panels

Data model (existing)

TableFields used for trends
panelsid, collected_at, created_at
markerspanel_id, name, value, unit, ref_low, ref_high

Date for x-axis

effectiveDate = panel.collectedAt ?? panel.createdAt

Sort points ascending by effectiveDate. Skip markers where value is null.

Marker matching (v1)

Exact string match on markers.name. A marker is trendable when the same name appears in ≥2 panels with numeric values.

Routes (shipped)

MethodPathReturns
GET/api/trends/markersNames trendable across panels
GET/api/trends?marker=HemoglobinTime series for one marker
GET/api/trends/insights?marker=…Cached insight markdown (fingerprint-validated)
POST/api/trends/insightsStream NDJSON tokens from Ollama; persist on complete

Insights cache

fingerprint = hash(marker + sorted points)
Store in trend_insights table.
Invalidate when fingerprint changes (new panel, edited value).

Ollama uses chatStreaming for markdown prose (not JSON). Prompt should stay non-diagnostic — describe direction and reference range, not medical advice.
