Trend Chart API

LocalLab — marker time series across panels

Data model (existing)

TableFields used for trends
panelsid, collected_at, created_at
markerspanel_id, name, value, unit, ref_low, ref_high

Date for x-axis

effectiveDate = panel.collectedAt ?? panel.createdAt

Sort points ascending by effectiveDate. Skip markers where value is null.

Marker matching (v1)

Exact string match on markers.name. A marker is trendable when the same name appears in ≥2 panels with numeric values.

Suggested routes

MethodPathReturns
GET/api/trends/markersNames trendable across panels
GET/api/trends?marker=HemoglobinTime series for one marker

Response shape
