Cursor Surfaces

Which tool to reach for, and when — for solo app building

Surface How to open Use when
Tab Just type Finishing obvious lines, boilerplate, small completions
Inline Edit Cmd+K Editing a selected block — rename, tweak logic, local refactor
Agent Cmd+I Multi-file work, running commands, building features, fixing bugs
Plan Mode Shift+Tab in Agent New app ideas, unclear scope, architecture decisions — plan before code

Solo builder loop

  1. Plan — describe the idea; let Agent research and propose a plan
  2. Build — approve the plan; Agent implements the thinnest runnable slice
  3. Verify — ask Agent to run the app, tests, or linter
  4. Iterate — new Agent chat per distinct task; Inline Edit for tiny fixes
