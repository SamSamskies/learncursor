@ Context

Point Agent at what matters — don't make it guess.

Common @ mentions

MentionUse when
@filename You know the exact file — a route, schema, test, or config.
@folder/ A module or layer — @src/routes/, @tests/.
@Codebase Unfamiliar repo — "where is auth handled?" before you know file names.
@Docs Framework API you need Agent to follow — Drizzle, Express, etc.
@Web Current docs or error messages not in the repo.
@Commit (Diff of Working State) Uncommitted changes — scope review, commit message draft.
@Branch (Diff with Main) Full branch diff — PR body, pre-push review (formerly @PR).
@Terminals Command already failed — attach exact terminal output for Agent.

Decision rule

Know the file?     → @file
Know the area?     → @folder
Don't know either? → @Codebase first, then narrow
