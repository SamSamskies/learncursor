Plan Mode

When to plan first, and how to recover when builds go wrong

Escalation rule

Task shapeSurface
One route mirroring an existing one Agent + @ files
Schema + routes + tests (3+ files) Plan Mode → Build
New app idea, stack unclear Plan Mode (frontier model)
One-line fix in a known file Inline Edit Cmd+K

Open Plan Mode

Shift+Tab in the Agent input, or pick Plan from the mode dropdown.

Plan → Build loop

  1. Prompt — goal, constraints, done-when (same anatomy as Agent)
  2. Answer — Agent asks clarifying questions; reply in chat
  3. Review plan — edit scope, file list, and order before any code
  4. Build — switch to Composer or Auto; check model didn't reset
  5. Verify — verify loop on the full diff

Pro model picks (Cursor Pro)

PhaseModel
Plan + refine Opus or GPT-5.x — locked, not Auto
Build Composer 2.5 or Auto

When the build goes wrong

Don't patch endlessly → revert → refine plan → build again

Spending time on a precise plan is cheaper than steering a bad multi-file diff. Save plans to the workspace for later reference (Save to workspace).
