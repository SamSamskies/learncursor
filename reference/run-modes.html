Run Modes

Formerly “YOLO mode” — how Agent runs shell, MCP, and Fetch without asking.

Where to configure

Settings → Agents → Approvals & Execution (local agents only; cloud agents ignore Run Modes).

Three modes

ModeBehaviorUse when
Auto-review Allowlisted calls run; others sandbox when possible; classifier reviews the rest Default — fewer prompts, safety layer
Allowlist Only listed commands auto-run (optional sandbox) Tight, repeatable command set
Run Everything Zero prompts — full machine access Trusted repo, you accept the risk (old YOLO)

Auto-review config files

FileScope
~/.cursor/permissions.jsonAll projects on this machine
.cursor/permissions.jsonOne repo — commit to share
 
{
  "autoRun": {
    "allow_instructions": [],
    "block_instructions": [
      "Every git push --force should require approval.",
      "Every rm -rf command should require approval."
    ]
  }
}

Sandbox (separate from mode)

  • Config: ~/.cursor/sandbox.json or .cursor/sandbox.json
  • Limits file + network reach for supported shell commands
  • macOS: Seatbelt — no extra setup

Built-in protections (always on)

  • File-deletion protection — blocks auto rm
  • External-file protection — blocks writes outside workspace
  • Browser protection — blocks auto browser tools

Stack with hooks

  • Run Modes — when Agent asks vs auto-runs
  • Hooks — deterministic block/allow on shell events
  • Verify loop — you still read diffs and run done-when yourself

Terminal hangs?

  • Disable heavy prompts (Powerlevel10k) when CURSOR_AGENT is set
  • Try Legacy Terminal under Settings → Agents
  • Full restart (Cmd+Q), not just reload window
